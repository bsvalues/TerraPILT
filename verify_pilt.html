PILT Calculation Verification

Test Case 1: Basic PILT Calculation

Testing a district with $10,000,000 assessed value, 0.0025 levy rate, and $0 deduction.

Calculation:

Base PILT = Assessed Value × Levy Rate

Base PILT = $10,000,000 × 0.0025 = $25,000

PILT Due = Base PILT - Deduction

PILT Due = $25,000 - $0 = $25,000

Test Case 2: PILT with Deduction

Testing a district with $5,000,000 assessed value, 0.0025 levy rate, and $2,500 deduction.

Calculation:

Base PILT = Assessed Value × Levy Rate

Base PILT = $5,000,000 × 0.0025 = $12,500

PILT Due = Base PILT - Deduction

PILT Due = $12,500 - $2,500 = $10,000

Test Case 3: Aggregation

Testing the aggregation of multiple districts.

Total Assessed Value = $10,000,000 + $5,000,000 = $15,000,000

Total Base PILT = $25,000 + $12,500 = $37,500

Total Deduction = $0 + $2,500 = $2,500

Total PILT Due = $25,000 + $10,000 = $35,000

Test Case 4: What-If Analysis

Testing the what-if analysis with adjusted values.

District 1: Change levy rate from 0.0025 to 0.003

District 2: Increase assessed value by 10% and change deduction to $5,000
